# Zen (Prod)

An unofficial personal fork of Zen Browser with Arc-style site-search activation,
provider-colored badges, native browser commands, and a top toolbar.

## Install

Drag Zen (Prod).app into Applications, eject this disk, and launch Zen (Prod).
This package contains a universal macOS application for Apple Silicon and Intel.
Native release testing was performed on Apple Silicon; Intel hardware testing
has not been performed. Windows and Linux packages are not provided.

Official Zen and Zen (Dev) remain separate applications. Your profile is created
under ~/Library/Application Support/Zen Personal/Production on your own Mac.
No developer bookmarks, cookies, passwords, accounts or extensions are included.
Search aliases use your configured search engines; importing another person's
profile is not required. The app opens website links using macOS's normal browser
handling; choosing it as the default browser is optional.

## Updates

Automatic browser-version updates are disabled. Download future releases from
https://github.com/kimkhoi2202/zen-browser-personal/releases and replace the closed
application in Applications. Your profile is separate from the application.
Back up your profile before an engine upgrade. This fork is maintained separately
from official Zen, including its security-update schedule.
